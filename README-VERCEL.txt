SITE DR. DANIEL LUNIERE — PRONTO PARA VERCEL

Este ZIP contém um site estático completo.

Para publicar pelo Vercel:
1. Na tela "Add New Project", escolha "Import a Zip file".
2. Selecione este arquivo ZIP.
3. Clique em Deploy.

Para publicar pelo GitHub:
1. Extraia o ZIP em um computador.
2. Envie TODOS os arquivos extraídos para a raiz do repositório.
3. Confirme que index.html está na raiz (fora de qualquer pasta).
4. No Vercel, importe o repositório.

Configuração no Vercel:
- Framework Preset: Other
- Build Command: deixe vazio
- Output Directory: .

O pacote já inclui SEO: título, meta description, palavras-chave,
Open Graph, Twitter Card, dados estruturados para clínica odontológica,
robots.txt, sitemap.xml e configuração de cache para Vercel.
